# Warriors Thrive Life App

Prototype of the Warriors Thrive sickle cell companion app from Hills Games Medical Entertainment.
Live at https://gerarddhills.github.io/warriors-thrive-life-app/

Prototype only: not medical advice, and not for real patient information. Data stays on each person's device.
In an emergency, call 911.

## Lesson videos (v7)

Six 1-minute character lessons (ACS, stroke signs, fever, spleen, pain crisis plan, priapism) play from the Learn library. The build script that makes the title, key-point and end cards, aligns captions to the approved scripts and assembles each video is in `tools/videos/`.

## Crisis Watch 2.0 (v8)

Personal pain-crisis forecast from smartwatch data (Apple Health export, CSV, typed-in readings or demo data), app data and the warrior's own triggers, with weather triggers and alerts. Draft model `cw-0.1-heuristic`, not validated. It is a research feature.
